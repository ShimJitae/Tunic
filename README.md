# Tunic

1. **프로젝트 개요**  
맵을 탐색하며 일반 적과 보스를 상대하는 3D 쿼터뷰 액션 게임입니다.

2. **실행 방법**  
   게임 시작 버튼을 통해 메인 게임에 진입합니다. 이동 `WASD/방향키`, 공격 `X`, 회피 `Z`입니다.

3. **핵심 플레이 흐름**  
   타이틀에서 시작 → 메인 맵 탐색·전투 → 보스 방 진입·보스전 → `Game Clear` 결과 화면 및 타이틀 복귀 순서로 진행됩니다.

4. **주요 기능 목록**
   플레이어 이동, 공격, 회피
   일반 몬스터 AI
   보스 몬스터 AI
   시네머신 카메라 연출

5. **프로젝트 구조**  
   `01_Assets` 입력, `02_Scripts` 로직, `03_Data` ScriptableObject, `04_Prefabs`, `05_Animation`, `06_Scenes`, `07_Behavior`로 구성되며 핵심 코드는 `PlayerController`, `EnemyBrain`, `SceneLoadManager`입니다.

6. **핵심 로직 설명**  
   HFSM를 통한 플레이어/일반 몬스터 구현
   Behavior Graph를 통한 보스 몬스터 구현
   MVP 패턴을 적용한 UI 업데이트

7. **적용한 심화 기술과 선택 이유**  
   UnityHFSM은 복잡한 플레이어·적 상태 관리에, Behavior Graph는 보스 패턴 확장에 사용했으며 MVP와 ScriptableObject로 UI 및 밸런스 데이터를 분리했습니다.

8. **성능 개선 내역**  
   Profiler에서 Ground 오브젝트와 적 추적 반복 계산을 병목으로 확인해 메시를 통합하고, 추적 결과를 `0.1초`간 캐시하며 거리 비교에 `sqrMagnitude`를 사용했습니다.

9. **개발 중 문제와 해결 과정**  
   보스 몬스터 떨림 현상 - 추격값과 후퇴값 사이에 여유 구간을 주어 해결
   공격 대상 중복 피격 현상 - HashSet에 타격한 대상을 저장해두고 다시 타격되지 않도록함.

10. **개선하고 싶은 점**  
    씬 이동 시 UniTask를 활용한 비동기 씬 로딩 흐름으로 리팩토링하고 싶음.
